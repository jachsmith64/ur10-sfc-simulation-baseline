## 2. 一页主流程（只适用于 V1.3）

以下命令仅记录入口语义，本轮没有执行。

1. **B01 人员核对输入与配置。** 确认 CSV、模型、Python 依赖和输出目录。若要重建扰动，单独选择 `python main.py --reconstruct`；若已存在匹配冻结包，可从第 5 步开始。
2. **B02 读实验序列并去慢偏移。** 读时间、名义沿程、横向误差、视觉速度、相位；重采样到 1 ms 网格；按规定切窗。运动前、正向稳态、反向稳态、停止后各取一个中位数，三段固定余弦过渡连接成 b(t)，得 e_vib=e_raw−b。
3. **B03 构造长模板和模型响应。** 复制正/反向稳态窗并平滑拼缝，延长到覆盖约 60 秒，保留启动/换向/停止结构；沿程生成名义关节轨迹；仿真多正弦探测辨识 TCP 受力到位移的响应。
4. **B04 离线反演、迭代、冻结。** 从目标 e_vib 反演等效 Y 向扰动力 Fd；用无附加控制的 A0 仿真核对复现，再按残差修正，最多 5 轮。保存冻结力、参考序列、名义行程、频响和元数据。达到迭代上限也可写包，必须查看记录中的 gate。
5. **B05 人员另行选择 `python main.py --sweep`。** 从默认冻结包读取并校验力序列和名义行程，生成/读取名义关节轨迹。它不会自动先运行 reconstruct。
6. **B06 先 A0，再固定比较参数。** 先跑无附加抗振控制 A0，从其 Y 速度分布取 v_ref，再跑线性阻抗和三组 ASFC。每个 case 依次运行，不是五组同时仿真。
7. **B07 单 case 时间步循环。** 读当前模拟 TCP 位置/速度 → 计算附加控制力 → 映射成关节力矩；从冻结文件按当前时间取 Fd → 将外力施在 TCP 点 → 名义关节位置驱动与附加广义力共同推进一步 MuJoCo → 检查发散 → 下一步。
8. **B08 额外对照。** 主比较后进行扰动幅值 0.5/1/1.5 倍对照；慢偏移偏置 ±5、±10 µm 各自反演冻结扰动，只跑强 ASFC；之后整理事件响应和分相位分析。
9. **B09 保存与检查。** 写 case 时序、指标、总表、图、配置/清单/错误记录；可以再单独执行 `--check`。检查结果只代表具体检查项目，不能据一个“通过”认定仿真物理真实性已经验证。

### 入口优先级

`main.py` 先判断 reconstruct，再 check，再 sweep；同时写多个标志不是串行任务清单，前一个命中后就返回。V1.3 不带任务参数会显示帮助并返回 2。V1.2 的无参数行为不同，见第 7 节。

## 4. 数据与控制链：必须区分三个环节

### 4.1 原始记录 → 净振动 → 离线等效扰动

CSV 关键列：`time_s`（秒）、`nominal_along_mm`（毫米）、`cross_track_um`（微米）、`vision_speed_mm_s`（毫米/秒）、`phase`。序列插值为 1 ms，离散相位使用保持方式。插值提高网格密度，不会创造原相机没有测到的高频信息。

V1.3 的 b(t) 由四个稳定值及三条余弦过渡固定构造。稳态窗内 e_vib 中位数为零是构造结果，不是独立效果验证。保留 e_raw、b、e_vib 三者以便查清评价口径。

沿程变换成模型世界 X 方向位置（mm→m），Y 标称 −0.174 m，Z 标称 0.694 m，经阻尼最小二乘 IK 得到关节弧度轨迹。冻结外力以 N 表示，频域反演保留通带至 30 Hz、45 Hz 截止。Fd 是与该模型和参考相配的**等效力**，不是实验中测得的真实外力。

### 4.2 冻结重放

`FrozenDisturbance` 按仿真时间插值读 Fd，普通比较中不根据当前控制误差更新它。不同控制器比较使用同一冻结输入、同一名义运动；幅值试验明确乘比例，偏置试验明确另造冻结包，不能假称所有对照力数据逐点相同。

### 4.3 仿真在线闭环

每个时间步：

`模拟 TCP y、J_y·qdot → e=y−y_nominal、v=y_dot−y_nominal_dot → F_ctrl → J_TCP^T[0,F_ctrl,0] → MuJoCo 广义力 → 模拟响应`

- A0：附加抗振力为 0，**仍有模型关节位置伺服**。
- 线性：F=−K·e−B0·v。
- ASFC：F=−K·e−B0·v−μ|v|^(n−1)v。
- 默认 K=5000 N/m、B0=400 N·s/m；三组 (n,r)=(3,1)、(2,2)、(1.5,4)；μ=r·B0/v_ref^(n−1)。μ 在 case 前确定，运行中不自动调到效果最好。
- Fd 通过 `mj_applyFT` 施在 attachment_site 的 TCP 世界位置、所属 wrist_3_link，不是简单往刚体质心塞力；控制力矩与扰动力产生的广义力叠加。
- 控制器读的是**理想仿真状态**，不读取真实相机，不把 e_vib 文件当成逐步反馈测量；e_vib 用于反演参考/评价对照。
- e 的单位 m，输出误差常转成 µm；关节 rad，速度 rad/s，力 N、力矩 N·m、功率 W。控制误差参考是名义 Y，不是“当前模拟值−实验 e_vib”。

## 5. 时序、输出、失败与取消

- case 之间顺序执行；case 内没有相机采集或设备线程。1 kHz 指物理模拟步频，不表示真实时间每秒完成 1000 步。
- 时序数组主要保存 **mj_step 前**的状态/控制；发散检查发生在推进后。解释输入与响应时应考虑这个一步顺序。
- traces 默认每 5 点输出一次，即约 200 Hz；随后计算 RMS/峰峰值、Welch PSD、0–2.5 Hz 慢频带和 2.5–45 Hz 振动频带。抽样输出不自动证明已有完整抗混叠处理。
- 主比较五组后，幅值试验只用线性和强 ASFC；s=1 复用已跑结果。偏置试验保持控制参数，重建偏置对应力包后只运行强 ASFC。事件/相位项目是后处理，不是新的真实采集。
- 固定 `outputs/fd_packet` 和 `outputs/sweep` 等路径会重写同名输出，工程没有自动为每次运行创建独立历史快照；本轮没有触发这种写入。
- run_case 捕获普通 Exception，记录 FAILED/INVALID 和可能的部分指标；继续与否还取决于上层是否能得到必需的 A0 等结果。图生成局部失败可记录错误继续。
- **Ctrl-C 的 KeyboardInterrupt 不在普通 Exception 捕获内**；没有可保证总表完整写出的批次顶层 finally。已有文件可能留存，但不能假设当前 case 的内存数据已经写盘。
- 未实现实验硬件释放逻辑，因为此工程没有对应实机资源；不是漏写“相机关闭”步骤。

## 6. 流程疑点、记录支持及限制

| 疑点 | 证据 / 影响 | 使用文档时应保留的结论 |
|---|---|---|
| 自定义 --packet 与 sweep 脱节 | main 将 packet 传给 reconstruct/check；run_batch 使用模块默认 PACKET_DIR | 新建自定义包不意味着 sweep 自动用了它；需核对实际输出 manifest |
| 反演验收标志不是强制闸门 | 达到最大迭代仍写包；提前停止看残差，不同时要求 corr | 不可把“包写成功”写成“复现验收已通过” |
| q 轨迹缓存身份不足 | get_q_traj 用 along 的形状与数值判断复用 | 若模型/Y/Z 等改变但 along 未变，缓存适配性待核对 |
| 失败时序可能有未用零尾 | run_case 预分配数组；write_trace 对整段数组输出；状态里有 n_steps_done | 失败 case 不可将整张 CSV 都当有效样本；基于它的比较可能受影响 |
| --check 有跳过项 | 仿真结果缺失时部分检查不做；拟合 corr 可只打印 | “check 通过”应连同完成/跳过的具体项目解释 |
| 偏置试验参考列口径 | 偏置另造 Fd，但调用 run_case 传原 reference | trace 中 e_raw/b/e_vib 列可能仍是原口径，需结合该偏置包 metadata 解读 |
| 跨电脑旧路径 | fd_meta 的 source_csv 仍写 C:\Users\PC\Desktop\code\pre_program\… | 是历史记录，不是当前路径失效就代表本地数据不存在；当前根目录已列明 |
| 等效模型/插值/理想测量 | 模型 UR10e、输入原采样约 132 Hz、网格 1 kHz、理想状态反馈 | 不据此推断 CB3 实机控制效果、传感延迟或真实外力 |

### 11.3 慢偏移：保留误差源的离线共同前提

当前研究先稳定波动的慢中心，再比较抗抖。“稳定中心”不包括提前压小普通波纹或启停换向峰。不能因关节偏差难补而删除固定偏差，不能改remaining、覆写qpos或对各方案输出各自扣趋势来实现回零。

旧B顺序是“A原始误差→估计并扣b(t)→剩余波动反演Fd→仿真”，属于背景构造前去基线，不是跑完后把各曲线减均值。V1.3的余弦实现未被当前F替换；V1.2方向相关LOWESS是独立历史分叉，不因参考B就搬入当前方案。

当前F顺序是“旧无附加抗抖A0完整输出→普通阶段代表中心＋简单平缓连接→仅A0有限检查→冻结唯一公共纠偏→三方案经位置通道实际重新积分”。采用四平台及五次smoothstep，仅借鉴平台思路，不拟合每个波峰或事件芯部。各方案共用同一数组，不从各自结果重估基线。

源头关节/末端背景、配套导数和事件均保留；公共纠偏改变执行命令，反馈与评价仍相对于原工艺名义轨迹。公共居中贡献与抗抖贡献、公共位置代价与抗抖力/力矩代价分别报告。中心改善不自动等于波动宽度改善；无力学依据时不将位置量虚报为力或能量。

允许完整旧数据参与构造，但必须称为非因果、离线理想化共同条件，不能宣称在线预测或实机漂移已解决。残余几微米可接受，不为严格零继续追随波动，也不在纠偏后重标定误差幅值。平台窗排除冷初始化和主要事件/明显恢复；停后短尾只作近似参照，不证明长期停稳。初始纠偏非零可能形成命令阶跃，后续C2连接及导数平缓不代表初始无阶跃；不得偷偷预热或改初态。

### 11.4 控制反馈与执行通道

当前抗抖链为“位置误差及误差速度→反向控制力→关节力矩请求→执行通道→实际响应”，不自动退回早期APF虚拟外力再由另一套导纳生成运动的方案。控制器不读冻结Fd作直接抵消；离线反演可按A0复现残差修正，不能依据线性/SFC改善率优化输入。Fd是模型等效力，不是视觉测得的真实力。

TCP施力点、Jacobian坐标系、方向和单位必须一致，分别记录补偿来源与作用通道。位置m/μm、关节rad/°、力N、力矩N·m不能混用。当前F的tau/Kp位置适配依赖已核对的模型执行器及限幅条件；模型Kp＝5000 N·m/rad是该模型参数，不是CB3实测增益，URScript gain不能视作同一物理量。旧B直接加力矩也不证明实机可用同样接口。

当前F命令结构是“原名义q＋原冻结关节误差＋公共慢位置偏移＋原抗抖tau/Kp”；事件仅走既有等效外力通道，位置抗抖不再额外注入力矩。公共慢位置量采用已核对的静态小幅映射，不是新增动态阻抗/导纳。微补偿不能被当作改写工艺名义轨迹或其几何/速度约束的许可，评价零线不随执行命令移动。

当前控制、记录与评价共用effective Y和配套速度。remaining是输出等效项，不是已辨识真实柔性模态；新增补偿自身的执行误差仍未全面辨识。若使用目标速度，应区分原名义速度与新增纠偏命令速度；本轮固定名义Y速度为零，公共纠偏导数是命令诊断，不从反馈中扣除为新目标。
