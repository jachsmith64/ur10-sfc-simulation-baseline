## 从审查 ZIP 复算

用带 NumPy 的 Python，从解包后的目录执行：

```powershell
python -B -X utf8 .\verify_review.py .
```

该入口复算有效帧 FIT、RMSE、峰值时刻差、X 原始括号时序、参考函数、编码器差商和 5 Hz 低通。审查目录已含原始 A 时钟和紧凑物理轨迹，可在无 MuJoCo 或网络的情况下打开 HTML 和复算。SHA-256 清单覆盖整个包。

## 从 Git 完整重积分

在 Windows x64 安装或复用 Python 3.12.10、MuJoCo 3.15.0、Ruckig 0.19.4、NumPy 2.5.3、SciPy 1.18.1。用独立的 Git 检出复现，不改变原 G 树。所有新代码从仓库相对路径或调用参数读取数据。紧凑历史绑定在新项 `inputs/previous`，保留上一轮 A 的逐帧来源、名义 q、旧物理 Y/remaining 和真实 CB3 频响校验。源帧数组仍位于原 G 项的 `prepared_A`。审查包中的 `source_arrays` 是同字节副本。

```powershell
python -B -X utf8 .\G\20261116_A_multispeed\prepare_v02.py .\G\20261116_preprocess_timing\local\portable_V02
.\G\20261116_preprocess_timing\reproduce.ps1 -Python '<Python 3.12.10>' -V02Root .\G\20261116_preprocess_timing\local\portable_V02 -Out .\G\20261116_preprocess_timing\runs\repeat
```

两套绑定依赖在独立目录时，向 `reproduce.ps1` 指定 `-MuJoCoRuntime` 和 `-ScienceRuntime`。本轮 B 执行使用上一轮 `local/frozen_V02` 及其 `runtime_local`、`runtime_science`。原始 output 必须是新目录，R01 单片以 `-Trials X_P05_R01` 运行。使用继承的 offline 装载器和隔离实机保护。

窗口回执可用 `windows.py --output <新文件>` 从冻结原始数组复算。该文件只用于核证已经记录的边界，正式运行读取工作项内 `windows_frozen.json`。报告再生成使用 Python 3.14、NumPy 和 Matplotlib 3.11.1。

```powershell
python -B -X utf8 .\G\20261116_preprocess_timing\review_report.py --run .\G\20261116_preprocess_timing\runs\repeat
```

完整本机结果位于工作项 `runs/verified_A`，每次 `trace.npz`、采样、保护和执行事件可单独核对。先只使用包作 GPT 审查。
