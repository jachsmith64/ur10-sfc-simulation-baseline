## X 用途与端点局限

- P10 的 160 μm 位置变化记录在 7.946 ms 的主机间隔、16 ms 的柜端间隔上，旧主机导数为 20.14 mm/s。固定柜端映射、同戳冲突及三处短括号字段一致性处理后，全段名义绝对速度最大约 10.001 mm/s。5/10 mm/s、约 13/23 mm 指令行程和原启停换向保留。未另行设计 S 曲线或继续追溯 RTDE 根因。
- R01 旧 +90% 减速点约 3.818 s，稳健主减速点约 3.907 s。50% 和 80% 时长作为敏感性诊断，主横向窗口和基线没有因此移动。原六次结果和历史门槛单列。
- 六次 X 隔离对照在修正输入上积分，候选主事件时差绝对值最大 26.4 ms。样点括号与观察到的时钟残差合计约 13.7–15.9 ms，绝对采样延迟仍未知。P10 旧联合门槛失败，原因是新增远端位置过冲 **0.10875 mm**。这个限值继续作为诊断证据。源最大值映射前后相同，Y 重建后 P10 远端误差为 **0.12947 mm**，约为 23 mm 行程的 0.56%。拟合后三片 X 主事件观测绝对差最大约 24.5 ms。保留该局限作后续 S 曲线参考。
- 当前按用户更新的用途判断 X 足够。三片速度方向、量级、行程和主要事件相近；时间处理未产生翻倍速度，六次无饱和和保护停机。没有用控制柜速度的高频点态匹配作为 Y 前置条件。

## Y 基线可信范围

- 相机原帧时戳、幅值和有效帧未更改。重新按零外力 N 定标公共物理纠偏，维持方向反馈/评分参考分离，事件窗口保持。静态姿态重测 CB3 频响，沿 30/45 Hz 原方法从零反推，三个最佳解分别来自第 3、4、2 次反推。C 的观测 remaining 与导数始终为零。
- 三片均保留同力有无公共物理表的差分。在各片最佳 N 上，用原 ±1 N 脉冲通道作对照。原名义速度项保持相同，首次物理位移为 0.801 s，正负方向一致，关节状态由动力学积分。
- 静止窗仍有低于 80 的结果，P10 启动前、停止后抖动层 FIT 约 −110.99、51.81。全窗口原始及去参考统计按原值交付。主要窗口吻合只支持当前三片的离线 N 基线，实机和正式抑振比较没有开展。
