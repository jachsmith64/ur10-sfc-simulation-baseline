# 本轮优先使用的研究目标

用户在六次 X 积分完成后重新确认用途。X 提供合理基础运动及后续 S 曲线研究参考；相机 Y 是抑振研究主依据。继续复用有来源的时钟修正及原指令速度、行程与启停换向安排。本轮没有设计新的 S 曲线。

旧验收回执、事件标记、相对实测的逐点速度及 90% 时长、端点过冲、保护状态保留。旧 X 联合门槛作为历史诊断。当前在同一冻结动力学和既有 8 ms 命令路径下，以速度量级、方向、行程、主要启停换向、伪尖峰与失稳证据判断 X 用途。不能据一项辅助误差无限阻挡 Y。

允许按已有方案对同一三片从零重建 N。相机 Y、时间轴、窗口、方向参考和 5 Hz 估速不变。物理纠偏与反馈及评分分开；C 的 remaining 仍为零。使用原微补偿诊断。只形成待审候选，A 暂不操作。
