# 实际设置与差异

| 项目 | 归档基准 | 当前对照 |
| --- | --- | --- |
| 控制模式 | A0，N | N→A0、L→Alinear、S→ASFC，共三片各三次 |
| 积分入口 | 原 integrate 仅传 A0 | 使用原模式映射，零控制力断言限 N。增加证据记录和复算，沿用原动力学 |
| 运行时 | CPython 3.12.10、NumPy 2.5.3、SciPy 1.18.1、MuJoCo 3.15.0、Ruckig 0.19.4，OPENBLAS_NUM_THREADS=1 | 同一实际版本，受原 V02 离线守卫保护。规划关闭 |
| CB3 | 1 ms，六轴 Kp=5000 Nm/rad、Kd=500 Nms/rad，编译重力、惯量、被动阻尼与限幅 | 全部继承。每次独立初始化，试次内连续保持原运动 |
| 名义目标 | 各片锁定的 q_nom、qdot_nom、(Kd/Kp)qdot_nom，原初始 q 与零 qdot | 完全相同，速度前馈计入共同目标 |
| 等效力及背景 | 已审最佳 N 的 Fd，独立公共物理表，原 dq/dqd 和 pressure path-six-v1-r1 | 全部按同片已审字节身份复用。没有重新拟合 |
| 方向参考与剩余项 | A/N 校准的同一方向表，带保护事件和 C² 过渡；remaining 与导数为零 | 全部继承。各受控模式从本次物理状态因果采样 |
| 反馈设置 | estimator Q，branch V，5 Hz，1 阶，rho=0，seed=1001，独立相机噪声为零 | 全部继承。位置用相机，速度用带 pressure 的编码器误差差分后低通 |
| 传输与执行 | 相机 132 Hz，曝光后配置延迟 4 ms；编码器 8 ms、配置延迟 0；完整目标每 8 ms 更新并保持，执行附加延迟 0 | 全部继承。有效相机年龄 4.00–11.52 ms，编码器年龄 0 ms；时钟各自保持 |
| 抑振参数 | K=5000.0、B0=400.0、n=1.5、mu=70879.56438014314、gamma=1.0、linear_multiplier=1.0、r=4.0、v_ref=0.000509563 m/s、w_gamma=0.01 | 从归档回执读取并逐项核对。L 有弹簧和线性分项，S 同时使用非线性分项，N 三项全零 |
| 执行通道 | POSITION_EQUIV，Fd 独立外力，q 由积分产生 | 真实雅可比和原 Kp 映射到关节目标微补偿。背景与前馈留在 base，外加力通道仍仅接收 Fd |
| 指标 | 已审冻结窗口与方向参考 | 用原样窗口评分，过渡独立，静止保留；同输入严格复现 N。本轮的比较使用固定参数 |

实际控制模式以九次各自的 row.json 和 execution.json 为准。历史参数回执的 parameters.mode=ASFC 是共享参数配方来源字段，运行时模式由上表映射显式传入并核验。

R01、R02、P10 的既有正负微补偿证据直接带入。独立复算检查当前 L/S 正确走同一采样及控制通道，微补偿通过关节目标生效，三片物理 Y 与 N 均有可测差异。
