# A 误差账本与公共慢纠偏

| 项目 | 数据与作用位置 | N 与控制组 |
|---|---|---|
| A 视觉 | 固定二维标定投到世界 Y，保留原帧号、主机时间、相机计数、有效点。去除预运动中位数便于模型比较，输出原始层时加回同一个零点 | 用于离线 N 反推和评分。采样器从每次当下模型读取 |
| 旧 dq / dqd | V02 的 C 背景一期非零切片。dq 加在名义关节目标，dqd 随旧输入保留。实际 q 由伺服和动力学算出 | N 已计入，L/S 入口共享相同数组 |
| remaining | V02 末端观测剩余项。瞬时总观测为物理 Y 加 remaining。相机采样和可用延迟在其后发生 | N 反推扣除物理和 remaining 已解释贡献。该项固定，力只通过原 TCP Y 外力接口注入 |
| 编码器压力 | 旧 C 返回直线来源的 path-six-v1-r1。加在 8 ms 编码器代理的读数 | 三片长度都在旧压力记录范围。物理 Y 和 A 参照直接沿各自来源 |
| 独立额外相机噪声 | G 的 3 μm 独立项置零 | 本轮所有 G 条件共用零值 |
| 名义、伺服、微补偿 | RTDE target_tcp_pose 六维逆解。旧 SFC 和线性力经当前 J 的转置、关节位置等效补偿及内置伺服执行，完整六轴目标 8 ms 保持 | G 仅执行 N。控制与微补偿分支已接到同一执行路径，动态验证待门禁 |
| 物理重力 | CB3 编译重力为 [0, 0, -9.81] m/s²。G 的显式 gravity_offset 数组全零 | G 入口始终如此 |
| 公共慢纠偏 | 固定四平台。以无拟合外力的 N 总观测减同帧 A 的平台中位数，经初姿最小范数平移右逆得到关节修正，平台之间作 C2 五次过渡 | 一次生成。与最终反推力一起保存并锁定。保存无公共表与只加公共表的对照 |

拟合使用经旧 30/45 Hz 余弦带限反推的 TCP Y 等效力。每次按预设窗口的原帧比较 A 与 N，固定坐标、幅值和时钟。相机采样只利用当时可用物理结点。原始视觉与数学上可逆的参考处理都保留。线性和 SFC 的后滤波 5/20 Hz 属于反馈支路，反推频带单独记录。

拟合残差与观测剩余项在不同位置。A 视觉已混合真实运动、关节执行偏差和测量影响，可复算的 FIT 反映同步波形吻合程度。保留的旧 C 背景无法由当前 A 唯一分解。物理和观测 FIT 分开报告，三片整段及启动的物理 FIT 仍低于 80。

第 0 次保留无外力、公共表已启用的结果，第 1–4 次只迭代等效力。每片保留名义、源实际 q、初始速度、前 150 ms 的物理位移和公共表对 N 的实际影响。慢纠偏的建表数据和去慢漂移的共同评分参考分开保留在状态与锁定数组中。
